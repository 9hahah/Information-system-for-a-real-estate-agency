## Описание проекта

Информационная система для агентства недвижимости – десктопное приложение, предназначенное для подбора и выбора объектов недвижимости непосредственно в офисе агентства.

Система ориентирована на совместную работу сотрудников агентства и клиентов. Она должна предоставлять доступ к информации об объектах недвижимости, включая стоимость, площадь, расположение и другие характеристики, необходимые для выбора подходящего варианта.

В рамках проекта планируется разработать приложение для работы со следующими категориями недвижимости:

- Квартиры и жилые дома
- Земельные участки
- Коммерческие помещения

Цель проекта – упростить процесс подбора недвижимости, систематизировать информацию об объектах и повысить эффективность работы сотрудников агентства.

На текущий момент проект находится на начальном этапе разработки.

## База данных

Для хранения данных предварительно выбрана СУБД PostgreSQL.

В процессе проектирования предстоит определить состав сущностей, их атрибуты, связи и ограничения целостности данных.

Предварительно рассматриваются следующие сущности:

| Сущность | Назначение |
|:--|:--|
| Пользователи | Данные учетных записей и роли |
| Объекты недвижимости | Характеристики объектов и их стоимость |
| Категории | Классификация недвижимости |
| Подборки | Сохраненные варианты для клиентов |

Окончательная структура базы данных будет определена после анализа требований.

### Документация

По мере разработки будут подготовлены следующие материалы:

- `docs/database.md` – описание структуры базы данных.
- `docs/er-diagram.md` – описание модели данных.
- `database/schema.sql` – SQL-скрипт создания базы данных.
